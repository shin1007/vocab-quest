# Vocab Quest — UX デザイン

> ゲーム・まんが・アニメで**すでに知っているカタカナ語**を足場にして、英単語を「冒険」として学ぶアプリ。

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| キャッチコピー | 「知ってるカタカナが、英語へのワープポイントになる。」 |
| ターゲット | 中学生〜大学生、ゲーム・アニメ好きの社会人（英検3級〜準1級 / CEFR A2〜C1） |
| 学習上の強み | 音と大まかな意味をすでに知っている（＝ゼロからの暗記ではない）。残りの「正しい綴り・正確な意味・語源・類義語との差」を埋める |
| 体験の核 | **「あのポーションって、poison（毒）と兄弟だったのか！」**という“つながる驚き”を毎回届ける |

### 設計の3原則

1. **知っている → 知らなかった**：必ずなじみのあるカタカナ語から入り、語源・カタカナの罠・類義語で「意外な発見」を与える。
2. **失敗しても前に進む**：ミスは罰ではなく「復習モンスターの出現」に変換する。ゲームオーバーでも得た経験値は失わない。
3. **1回3分**：1バトル＝8問。通学中・ゲームの待ち時間にも終わる長さ。

## 3. ワールド構成

| エリア | テーマ | 収録例 | 敵キャラ |
|---|---|---|---|
| 🏰 剣と魔法の王国 | RPG・ファンタジー | potion, quest, dungeon, summon | 🐉 |
| ⚔️ 闘技場 | バトル・アクション | critical, combo, counter, rival | 🤖 |
| 🚀 宇宙ステーション | SF・ロボット | launch, gravity, dimension, portal | 👾 |
| 🏫 青春ストリート | 学園・スポーツ・ドラマ | tension, smart, claim, cunning | 👻 |

- 各エリアは「単語の 60% を★3以上」にすると**ボス戦**（類義語・語源問題だけの高難度バトル）が解放される。
- 青春ストリートは**カタカナの罠（和製用法とのズレ）**が多いエリアとして、他エリアよりやや後に推奨表示する。

> **著作権への配慮**：特定作品のキャラクター名・画像・台詞は使わず、「RPGの回復アイテム」のようなジャンル共通の“あるあるシーン”で文脈を示す。

## 4. バトル（クイズ）設計

### 4.1 問題タイプ

| # | タイプ | 出題 | 回答 | 狙い | 難度 |
|---|---|---|---|---|---|
| 1 | **カタカナ → 英語** | 「ポーション」+ シーン | 4択で正しい英単語 | 音から綴りへの橋渡し | ★ |
| 2 | **英語 → 意味** | `potion` | 4択で日本語の意味 | 正確な意味の確認 | ★ |
| 3 | **スペル錬成** | 「ポーション」+ 意味 | 文字タイルを並べる | 綴りの定着（産出） | ★★ |
| 4 | **語源パズル** | 「ラテン語 pōtiō『飲み物』から生まれたのは？」 | 4択 | 語源による精緻化 | ★★ |
| 5 | **類義語ハンター** | 「`elixir` の仲間は？」 | 4択 | 類義語ネットワーク | ★★★ |
| 6 | **カタカナの罠** | 「日本語の『テンション高い』を英語で言うと？」 | 4択 | 和製用法とのズレの修正 | ★★★ |

- カードの習熟度（後述の★）に応じて出題タイプを上げていく。★0〜1 はタイプ1・2、★2 でタイプ3・4、★3 以上でタイプ5・6 が混ざる。
- 同じ単語を連続して出さない。1バトル内で新規語は最大3語。

### 4.2 ゲーム的フィードバック

| 要素 | ルール | 意図 |
|---|---|---|
| ダメージ | 正解で敵HPを削る。基本10 × コンボ倍率 | 正解＝前進の手応え |
| コンボ | 連続正解で倍率 +0.5（最大×3） | 集中の持続 |
| クリティカル | 5秒以内の正解で ×2 と「CRITICAL!」演出 | 自動化（即答）を促す |
| ハート | 3つ。ミスで1つ減る。0で「撤退」 | 適度な緊張感 |
| 撤退時 | それまでの経験値は**全て獲得**。ミスした単語は「復習モンスター」に | 失敗の罰を小さくする |

### 4.3 回答直後の「ひらめきカード」

正誤にかかわらず、回答直後に 1 枚だけ小さなカードを表示する（2〜4秒で読める量）。

```
┌───────────────────────────────┐
│ ✅ 正解！   potion  ポーション │
│ 飲み薬、水薬                  │
│ 📜 ラテン語 pōtiō「飲み物」   │
│ 💡 poison（毒）と兄弟語！      │
│                    [ 次へ ▶ ] │
└───────────────────────────────┘
```

- 不正解時は**自分が選んだ誤答の意味も表示**し、混同の原因を解消する。
- 「カタカナの罠」がある語はカードに ⚠️ を付ける。

## 5. 成長・収集システム

### 5.1 単語カードの★（＝間隔反復のボックス）

ライトナー方式の5段階を「カードのレア度」として見せる。

| ★ | 状態 | 次の出題まで | 見た目 |
|---|---|---|---|
| ☆0 | 未発見 | — | シルエット |
| ★1 | 出会った | 当日 | ブロンズ |
| ★2 | 覚えかけ | 1日 | シルバー |
| ★3 | 定着中 | 3日 | ゴールド |
| ★4 | マスター | 7日 | プラチナ（キラ演出） |
| ★5 | レジェンド | 21日 | レインボー |

- 正解で★+1、不正解で★-1（最低★1）。「カードが進化する」演出で、復習そのものを報酬にする。
- **デイリー復習**：期限が来たカードは「再出現モンスター」としてホームに表示。

### 5.2 語根クリスタル

- 同じ語根をもつ単語（例：`mon`「警告する」→ summon, monster）を**すべて★3以上**にすると「語根クリスタル」が完成。
- クリスタル画面では、アプリ未収録の仲間の語（monitor, demonstrate…）も表示し、**1つの語根から語彙が広がる**体験を作る。

### 5.3 プレイヤーレベル・連続記録

- 経験値でプレイヤーレベルが上がる（必要XP = 100 × 現在レベル）。
- 連続ログイン日数（ストリーク）を表示。ただし**途切れても罰はない**（「おかえり」メッセージのみ）。

## 6. 図鑑（単語リスト参照）

学習者がいつでも辞書として引けるように、**未発見の語も含めて全語を閲覧可能**にする（未発見はグレー表示で収集欲を刺激）。

### 6.1 一覧画面

- 検索（英語・カタカナ・意味）
- フィルター：エリア / ⚠️カタカナの罠のみ / ★
- カード：英単語・カタカナ・★・⚠️マーク

### 6.2 詳細画面の構成

| セクション | 内容 |
|---|---|
| ヘッダー | 英単語 / カタカナ / 品詞 / CEFR / 🔊 発音（Web Speech API） |
| 意味 | 英語での正確な意味 |
| 🎮 シーン | ゲーム・まんがでの“あるある”な使われ方 |
| ⚠️ カタカナの罠 | 日本語での用法とのズレ（該当語のみ） |
| 💬 例文 | 英文＋和訳 |
| 📜 語源 | 由来言語と原義、意味の変遷ストーリー |
| 💎 語根 | 語根チップ（タップで語根クリスタルへ） |
| 🌳 同じ語源の仲間 | family 語 |
| 🔀 類義語 | 各類義語の **意味・ニュアンスの違い・語源** の表 |

## 7. 画面フロー

```
[初回起動]
  └ オンボーディング（30秒）
      ├ 好きなジャンルを選ぶ（複数可）
      └ チュートリアルバトル（3問：必ず正解できる易問）
[ホーム = ワールドマップ]
  ├ ヘッダー: Lv / XP バー / 🔥ストリーク
  ├ デイリー復習（期限切れカード数）
  ├ エリア一覧（進捗バー、ボス解放状態）
  └ タブ: 🗺 ワールド | 📖 図鑑 | 💎 語根 | 📊 記録
[バトル] → [ひらめきカード] ×8 → [リザルト]
  リザルト: 獲得XP / 最大コンボ / 新カード / ★アップ / レベルアップ演出
```

## 8. アクセシビリティ・配慮

- 正誤は色だけでなく ✅/❌ アイコンとテキストで示す（色覚多様性）。
- タイマーはクリティカル判定のみに使い、**制限時間で不正解にはしない**（焦りによる離脱を防ぐ）。
- 音声読み上げボタンを全単語に。効果音・演出は設定でオフにできる。
- ダークテーマ基調（夜間のプレイを想定）、タップ領域 44px 以上。

## 9. 計測指標（KPI）

| 指標 | 目的 |
|---|---|
| D1 / D7 継続率 | 習慣化できているか |
| 1バトルあたり正答率（目標 70〜85%） | 難易度が適切か（高すぎても低すぎても離脱） |
| ★4 以上のカード数 | 長期記憶への定着 |
| 図鑑の詳細閲覧率 | 語源・類義語コンテンツが読まれているか |
| 撤退率 | 難易度が高すぎないか |

## 10. データ構造

単語データは `data/words.json`、語根データは `data/roots.json`。人間向けの一覧は `docs/WORD_LIST.md`（自動生成）。

```jsonc
{
  "id": "potion",
  "word": "potion",
  "katakana": "ポーション",
  "pos": "名詞",
  "area": "fantasy",            // fantasy | battle | scifi | story
  "cefr": "B2",
  "meaning": "（薬・魔法の）飲み薬、水薬",
  "scene": "RPGの定番回復アイテム。",
  "gap": "（任意）日本語での用法とのズレ",
  "trapQuiz": {                   // （任意）「カタカナの罠」問題。gap がある語のみ
    "question": "…", "answer": "…", "wrong": ["…", "…", "…"]
  },
  "example": { "en": "...", "ja": "..." },
  "etymology": { "origin": "ラテン語 pōtiō「飲み物」…", "story": "…" },
  "roots": ["pot"],               // roots.json の id
  "family": ["poison（毒）"],
  "synonyms": [
    { "word": "elixir", "meaning": "霊薬", "nuance": "…", "etymology": "…" }
  ]
}
```
