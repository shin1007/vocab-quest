# Vocab Quest — UX デザイン

> ゲーム・まんが・アニメで**すでに知っているカタカナ語**を足場にして、英単語を学ぶアプリ。
> 学習の仕組みはふつうの単語アプリ。**見た目だけ**をいまどきのゲーム UI に寄せる。

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| キャッチコピー | 「知ってるカタカナを、英語にしよう。」 |
| 機能 | レッスン・クイズ・間隔反復の復習・単語帳・語根。**HP・敵・経験値・レベル・通貨・アイテムなどのゲームの仕組みは持たない** |
| 見た目 | モバイルゲームのロビー／メニュー画面風（§8） |
| ターゲット | 中学生〜大学生、ゲーム・アニメ好きの社会人（英検3級〜準1級 / CEFR A2〜C1） |
| 学習上の強み | 音と大まかな意味をすでに知っている（＝ゼロからの暗記ではない）。残りの「正しい綴り・正確な意味・語源・類義語との差」を埋める |
| 体験の核 | **「あのポーションって、poison（毒）と兄弟だったのか！」**という“つながる驚き”を毎回届ける |

### 設計の3原則

1. **機能は学習のためだけに置く**：画面に出る数字（習熟度・正答率・連続日数・定着語数）はすべて学習の状態そのもの。ゲーム的な報酬の数字は置かない。
2. **間違えても責めない**：不正解は「おしい！」＋自分が選んだ誤答の意味を見せる。わからなければ「わからない」で答えを見られる。
3. **1回3分**：1回のレッスン＝6〜8問。通学中・待ち時間にも終わる長さ。

> **著作権への配慮**：特定作品のキャラクター名・画像・台詞は使わず、ジャンル共通の“あるある”（`scene`）で例示する。

## 2. 学習の流れ

```
 [ホーム] ─→ [レッスン紹介] ─→ [クイズ ×6〜8問] ─→ [結果]
    │  ↑                        （1問ごとに解説カード）      │
    │  └──────────────────────────────────────────────┘
    ├─ 🔁 復習（期限が来た語だけで出題）
    ├─ 📖 単語帳（全語を辞書として参照）
    ├─ 🧩 語根（同じ語根の語をまとめて見る）
    └─ 📊 記録（習熟度の分布・設定）
```

| ステップ | 学習上の役割 |
|---|---|
| レッスン | 想起練習（retrieval practice） |
| 解説カード | 精緻化（語源・誤答の意味・カタカナの罠で記憶の手がかりを増やす） |
| 復習 | 間隔反復（spaced repetition） |
| 単語帳 | いつでも引ける辞書。語源・例文・類義語 |
| 語根 | 語根で単語をまとめて覚える（転移） |

---

## 3. トピックとレッスン

単語は4つのトピック（`data/words.json` の `area`）に分かれる。

| トピック | 内容 | 収録例 |
|---|---|---|
| 🏰 ファンタジー | RPG・剣と魔法 | potion, quest, dungeon, summon |
| ⚔️ アクション | バトル・格闘 | critical, combo, counter, rival |
| 🚀 SF | 宇宙・ロボット | launch, gravity, dimension, portal |
| 🏫 学園・ドラマ | スポーツ・日常 | tension, smart, claim, cunning |

- 各トピックの単語を **CEFR の易しい順**に並べ、約6語ずつのレッスンに分ける。
- **すべてのレッスンを最初から選べる**（ロックはしない）。ホームには「NEXT」として、まだ終えていない最初のレッスンをおすすめ表示する。全部終えたら習熟度が一番低いレッスンをすすめる。
- レッスンを始めると、そのレッスンの語に、同じトピックの復習期限が来た語を足して最大8問にする。

## 4. 問題

### 4.1 問題タイプ

| # | タイプ | 出題 | 回答 | 狙い | 出題される習熟度 |
|---|---|---|---|---|---|
| 1 | **カタカナ → 英語** | 「ポーション」+ シーン | 4択で正しい英単語 | 音から綴りへの橋渡し | 0〜2 |
| 2 | **英語 → 意味** | `potion` | 4択で日本語の意味 | 正確な意味の確認 | 0〜2 |
| 3 | **つづり** | 「ポーション」+ 意味 | 文字タイルを並べる | 綴りの定着（産出） | 2〜 |
| 4 | **語源** | 「ラテン語 pōtiō『飲み物』から生まれたのは？」 | 4択 | 語源による精緻化 | 2〜 |
| 5 | **類義語** | 「`elixir` の類義語は？」 | 4択 | 類義語ネットワーク | 3〜 |
| 6 | **カタカナの罠** | 「日本語の『テンション高い』を英語で言うと？」 | 4択 | 和製用法とのズレの修正 | 3〜（罠がある語のみ） |

- 出題文の中に答えの単語（や派生形）が含まれる場合は「＿＿＿」で伏せる。
- 制限時間はない。

### 4.2 補助

| ボタン | 効果 |
|---|---|
| 💡 ヒント | 問題タイプに応じたヒントを表示（例：カタカナ→英語なら意味、語源ならカタカナ表記）。1問1回 |
| ↩ 1文字もどす | つづり問題のみ |
| わからない | 不正解として扱い、答えと解説を表示する |

### 4.3 解説カード

正誤にかかわらず、回答直後に表示する（2〜4秒で読める量）。

```
┌───────────────────────────────┐
│ ✓ 正解！             ■■□□□  │  ← 緑／赤の帯。右は習熟度
├───────────────────────────────┤
│ potion  ポーション        🔊  │
│ （薬・魔法の）飲み薬           │
│ 📜 ラテン語 pōtiō「飲み物」    │
│ 💡 poison（毒）と兄弟語！      │
│ [📖 くわしく]       [つぎへ ›] │
└───────────────────────────────┘
```

- 不正解時は**自分が選んだ誤答の意味も表示**し、混同の原因を解消する。
- 類義語問題ではその類義語のニュアンスを、罠がある語は ⚠️ の注意書きを添える。

### 4.4 結果画面

正答率・正解数・連続日数と、**新しく出会った語／習熟度が上がった語／もう一度確認したい語（間違えた語）**を表示。各語をタップすると単語帳の詳細を開ける。途中でやめた場合も、そこまでの結果を表示して記録する。

## 5. 習熟度と復習

### 5.1 習熟度（ライトナー方式の5段階）

| 習熟度 | 名前 | 次の出題まで |
|---|---|---|
| 0 | 未学習 | — |
| 1 | 出会った | 当日 |
| 2 | 覚えかけ | 1日 |
| 3 | 定着中 | 3日 |
| 4 | 得意 | 7日 |
| 5 | 完璧 | 21日 |

- 正解で +1、不正解で −1（最低1）。5マスのメーターで表示し、段階ごとに色が変わる（ピンク → 黄 → 緑 → 水色 → 紫）。
- 習熟度3以上を「定着した語」として数える。
- 期限が来た語はホームの「きょうの学習」に件数が出て、「復習する」で最大8問出題する。

### 5.2 語根

- 同じ語根をもつ単語（例：`mon`「警告する」→ summon, monster）を**すべて習熟度3以上**にするとコンプリート。
- アプリ未収録の仲間の語（monitor, demonstrate…）も表示し、**1つの語根から語彙が広がる**体験を作る。

### 5.3 連続日数

- 1回でも学習した日を数える。**途切れても罰はない**（次に学習したとき「おかえりなさい」と表示するだけ）。

---

## 6. 単語帳

いつでも辞書として引けるように、**未学習の語も含めて全語を閲覧可能**にする。

- 一覧：検索（英語・カタカナ・意味・類義語）、トピックで絞り込み、⚠️カタカナの罠のみ
- 詳細：英単語／カタカナ／品詞／CEFR／🔊発音、意味、習熟度、🎮シーン、⚠️カタカナの罠、💬例文、📜語源、🧩語根、🌳同じ語源の仲間、🔀類義語（意味・ニュアンス・語源の表）

## 7. 画面構成

```
[ホーム]  ← タブ: 🏠ホーム | 📖単語帳 | 🧩語根 | 📊記録
  ├ はじめに（初回のみ）→「はじめる」でファンタジーのレッスン1へ
  ├ きょうの学習（連続日数・定着した語・復習件数／🔁復習する）
  ├ NEXT（おすすめのレッスン）
  ├ トピックごとのレッスン一覧（進捗バー・定着率リング）
  └ ことばの小ネタ（ランダムな語源トリビア）
[レッスン紹介]（ボトムシート）単語一覧と習熟度 → 始める
[クイズ]  タブとヘッダーを隠した集中モード
  ✕ やめる | 1問ごとの ○× が色でわかるステップバー | 3/8
  問題カード → 解説カード
[結果] → ホームへ／もう一度
```

## 8. ビジュアル

いまのモバイルゲームのロビー／メニュー画面で主流の、**太いアウトライン＋固い影＋ぷっくりした立体ボタン**のスタイル。機能はゲームにせず、手触りだけをゲームにする。

| 要素 | 仕様 |
|---|---|
| 背景 | 紫〜群青のグラデーション＋ドットパターン、上部にピンクの光 |
| カード | 白地・3px の濃紺アウトライン・下方向の固い影（ぼかしなし）・角丸22px |
| ボタン | 黄（主要）／緑（正解後・復習）／白（補助）／赤（リセット）。上に光沢、下に濃い縁、押すと沈む |
| 見出し | Dela Gothic One。白文字＋太い縁取り＋落ち影（ゲームタイトル風） |
| 本文 | M PLUS Rounded 1c（丸ゴシック） |
| 選択肢 | A〜D のキーキャップ付き。正解は緑＋✓でバウンド、不正解は赤＋✗で横に揺れる |
| つづり | 黄色のキーキャップ風タイルと点線のスロット |
| 進捗 | ステップバー（問題ごと）、進捗バー（レッスン）、円形リング（トピック・語根）、5マスメーター（語） |
| 結果 | アイコンの後ろで光線が回る演出（正答率70%以上） |
| タブ | 画面下に浮かぶ白いバー。選択中は黄色のピル |
| トピック色 | ファンタジー＝紫、アクション＝オレンジ、SF＝水色、学園・ドラマ＝緑 |

---

## 9. アクセシビリティ・配慮

- 正誤は色だけでなく ✓/✗ と文言で示す（色覚多様性）。
- 制限時間はない。
- 音声読み上げボタンを全単語に。`prefers-reduced-motion` で演出を止める。
- タップ領域 44px 以上。キーボード操作時はフォーカスリングを表示。

---

## 10. 計測指標（KPI）

| 指標 | 目的 |
|---|---|
| D1 / D7 継続率 | 習慣化できているか |
| 1回あたり正答率（目標 70〜85%） | 難易度が適切か |
| ヒント・「わからない」の使用率 | 難しすぎないか |
| 途中でやめた率（レッスン別） | 長さ・難易度の調整 |
| 習熟度4以上の語数 | 長期記憶への定着 |
| 単語帳の詳細閲覧率 | 語源・類義語コンテンツが読まれているか |

## 11. データ構造

単語データは `data/words.json`、語根データは `data/roots.json`。人間向けの一覧は `docs/WORD_LIST.md`（自動生成）。トピック・問題タイプ・習熟度の定義は `app/app.js` 冒頭の定数。

```jsonc
{
  "id": "potion",
  "word": "potion",
  "katakana": "ポーション",
  "pos": "名詞",
  "area": "fantasy",            // fantasy | battle | scifi | story（＝トピック）
  "cefr": "B2",                 // レッスンの並び順に使う
  "meaning": "（薬・魔法の）飲み薬、水薬",
  "scene": "RPGの定番回復アイテム。",
  "gap": "（任意）日本語での用法とのズレ",
  "trapQuiz": {                   // （任意）「カタカナの罠」問題。gap がある語のみ
    "question": "…", "answer": "…", "wrong": ["…", "…", "…"]
  },
  "example": { "en": "...", "ja": "..." },
  "etymology": { "origin": "ラテン語 pōtiō「飲み物」…", "story": "…" },
  "roots": ["pot"],               // roots.json の id
  "family": ["poison（毒）"],
  "synonyms": [
    { "word": "elixir", "meaning": "霊薬", "nuance": "…", "etymology": "…" }
  ]
}
```

学習記録はブラウザの localStorage（`vocab-quest-save-v3`）。旧 RPG 版のセーブ（`v2`）があれば、習熟度・連続日数・回答数だけを引き継ぐ。
