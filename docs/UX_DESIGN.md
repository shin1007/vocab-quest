# Vocab Quest — UX デザイン

> ゲーム・まんが・アニメで**すでに知っているカタカナ語**を足場にして、英単語を学ぶアプリ。
> 学習の仕組みはふつうの単語アプリ。**見た目だけ**をいまどきのゲーム UI に寄せる。

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| キャッチコピー | 「知ってるカタカナを、英語にしよう。」 |
| 機能 | 次のn語・クイズ・間隔反復の復習・単語帳・語根。**HP・敵・経験値・レベル・通貨・アイテムなどのゲームの仕組みは持たない** |
| 見た目 | モバイルゲームのロビー／メニュー画面風（§8） |
| ターゲット | 中学生〜大学生、ゲーム・アニメ好きの社会人（英検3級〜準1級 / CEFR A2〜C1） |
| 学習上の強み | 音と大まかな意味をすでに知っている（＝ゼロからの暗記ではない）。残りの「正しい綴り・正確な意味・語源・類義語との差」を埋める |
| 体験の核 | **「あのポーションって、poison（毒）と兄弟だったのか！」**という“つながる驚き”を毎回届ける |

### 設計の3原則

1. **機能は学習のためだけに置く**：画面に出る数字（習熟度・正答率・連続日数・定着語数）はすべて学習の状態そのもの。ゲーム的な報酬の数字は置かない。
2. **間違えても責めない**：不正解は「おしい！」＋自分が選んだ誤答の意味を見せる。わからなければ「わからない」で答えを見られる。
3. **区切りは自分で決める**：レッスンに分けず、「次の n 語」（50／100／150／200語から選ぶ）をまとめて出題する。多くの語を間をあけて何度も思い出すほうが定着する（Kornell 2009、Nakata & Webb 2016）ので、時間があれば大きめの数を選べる。途中でやめても続きから再開できるので、通学中・待ち時間に数分ずつ進められる。

> **著作権への配慮**：特定作品のキャラクター名・画像・台詞は使わず、ジャンル共通の“あるある”（`scene`）で例示する。

## 2. 学習の流れ

```
 [ホーム] ─→ [クイズ n語×2回前後] ─→ [結果] ─→ 次のn語へ
    │  ↑                        （1問ごとに解説カード）      │
    │  └──────────────────────────────────────────────┘
    ├─ 🔁 復習（期限が来た語だけで出題）
    ├─ 📖 単語帳（全語を辞書として参照）
    ├─ 🧩 語根（同じ語根の語をまとめて見る）
    └─ 📊 記録（習熟度の分布・設定）
```

| ステップ | 学習上の役割 |
|---|---|
| 次のn語 | 想起練習（retrieval practice） |
| 解説カード | 精緻化（語源・誤答の意味・カタカナの罠で記憶の手がかりを増やす） |
| 復習 | 間隔反復（spaced repetition） |
| 単語帳 | いつでも引ける辞書。語源・例文・類義語 |
| 語根 | 語根で単語をまとめて覚える（転移） |

## 3. コースと「次のn語」

単語はジャンル（RPG・格闘など）では分けない。dog や juice のような身近な語も、potion や scorpion のようなゲームの語も、**英検の級にあわせたざっくりしたレベル（`data/words.json` の `level`、1〜7）**にまとめて出す。

細かく分けすぎると「いまどのくらいの力なのか」がわかりにくいため、多くの人が知っている英検の級を目安にする。級は**英語としての難しさ**（つづり・意味の抽象度・使われる頻度）で決め、参考として CEFR も `cefr` に持っておく。カタカナとしてなじみがあっても、英語として難しい語（scorpion、alchemist など）は上の級に置く。

| level | 級 | 名前 | 目安 | 収録例 |
|---|---|---|---|---|
| 1 | 5級 | はじめの一歩 | 中学1年程度（CEFR A1） | dog, cat, bus, juice, cake |
| 2 | 4級 | くらしの基本 | 中学2年程度（A1〜A2） | sandwich, museum, ticket, dark |
| 3 | 3級 | 中学卒業 | 中学卒業程度（A2） | monster, recipe, ghost, castle |
| 4 | 準2級 | 高校なかば | 高校中級程度（B1） | treasure, armor, sword, witch |
| 5 | 2級 | 高校卒業 | 高校卒業程度（B1〜B2） | potion, quest, wizard, meteor |
| 6 | 準1級 | 大学なかば | 大学中級程度（B2〜C1） | incentive, scorpion, phoenix, venom |
| 7 | 1級 | マスター | 大学上級程度（C1〜C2） | paradigm, hegemony, golem, alchemist |

- **到達度**：各級の単語の8割が「定着中」以上になると、その級を「クリア」とする。5級から順に判定し、ホームに「○級「…」クリアまで あと N語」と進捗バーを出す。クリアした学習の結果画面ではお祝いのカードを出す。記録画面には級ごとの定着度を並べる。
- **例文の文法も級に合わせる**：語が5級でも例文に受け身や関係詞が入っていると読めないため、中学の学年の文法にそろえる。5級＝現在形・現在進行形・can・命令文、4級＝過去形・未来・助動詞・不定詞・動名詞・比較・接続詞、3級＝現在完了・受け身・関係代名詞・分詞の後置修飾まで。準2級より上は高校の文法なので制限しない。5級〜3級は `scripts/check_examples.py` が語の並びから確認する（例文の長さも5級9語・4級11語・3級13語まで）。
- 各コースの単語を、ジャンルが偏らないよう混ぜて並べる（id から決まる順なので毎回同じ）。似た語が固まると混同しやすいので、ジャンルを混ぜる並べ方は続ける。
- **レッスンには分けない**。ホームの「NEXT」は下のレベルから順に「次の n 語」を出し、各コースのカードからはそのコースの「次の n 語」を始められる（ロックはしない）。
- n はホームの NEXT で 50／100／150／200 語から選ぶ（初期値50語、選んだ数は保存。それ以外の保存値は50語に戻す）。1日の上限は設けず、区切りは学ぶ人が決める。新しい語を増やすほどあとの復習（新しい語1つにつき最初の数週間で4〜5回）も増えるので、多めに選んだときは復習がたまりすぎないよう様子を見る。
- 出す語は、まず「覚えかけ（出会ったが習熟度2未満）の語」、足りない分を「まだ出会っていない語」で埋めて n 語。復習期限が来た語は🔁復習で出す。
  - 各語を習熟度2（翌日に復習）まで上げるのが目標。まだ届かない語は、正解なら6問あと・不正解なら3問あとにもう一度出す（別の語をはさんで思い出す間隔を作る）。1回で同じ語は最大4回まで。
  - クイズ上部には、習熟度2に届いた語の割合を1本のバーで出す（20語以下なら語ごとのマス）。
  - 途中でやめても習熟度は1問ごとに保存されるので、覚えかけの語が次の n 語の先頭に入って続きから再開できる。結果画面の「▶ 次の n 語を覚える」でそのまま続けられる。
  - コースの語に全部出会い、全部が習熟度2に届いたら、習熟度の低い語から n 語を1回ずつの「練習」にする。
- セーブデータはレッスン制のころの完了印（`done`）・`courseVersion`・1日の上限（`newToday`・`newPerDay`）を読み込み時に捨てる。単語ごとの習熟度はそのまま使う。

## 3.5 似た単語セット

母音が1つちがうだけの語（hat / hut）、カタカナにすると同じになる語（light / right、best / vest）、英検によく出るつづりの似た語（desert / dessert、adapt / adopt、affect / effect）を、2〜3語のセットで覚える。データは `data/pairs.json`。

単語リストの中でカタカナが同じになる語（staff / stuff、bus / bath、coat / court、night / knight、role / roll など）は、かならずどれかのセットで一緒に練習できるようにする。`build_wordlist.py` が「カタカナが同じなのに似た単語セットがない組」を表示するので、0 組になるようにセットを足す。

| 種類 | 例 | 練習 |
|---|---|---|
| 🗣️ 母音のちがい | hat / hut、ship / sheep、walk / work | 空所補充＋聞き取り |
| 👅 L と R | light / right、rice / lice、collect / correct | 空所補充＋聞き取り |
| 👄 B と V | best / vest、boat / vote | 空所補充＋聞き取り |
| 😛 TH の音 | sink / think、mouse / mouth | 空所補充＋聞き取り |
| 👂 同じ音・別の語 | hear / here、weather / whether | 空所補充 |
| ✍️ つづりが似ている | desert / dessert、principal / principle | 空所補充 |
| 🧬 形が似た派生語 | sensible / sensitive、economic / economical | 空所補充 |

- セットの語が単語リストにも入っていてよい（1つの語が複数のモードに出る）。カタカナ語として定着している語（light、road、piece など）は単語リストにも入れる。
- 各セットには、レベル（級。1=5級〜7=1級）、ちがいの説明（`point`）、各語の発音記号・品詞・意味・例文を持たせる。例文にはその語そのもの（活用しない形）を入れ、ほかの語は入れない（空所補充にそのまま使うため。`build_wordlist.py` で検証）。
- 「似た語」タブ：種類で絞りこみ、🔈で聞きくらべ、セットごとの練習、まとめて練習（復習期限 → 未練習（やさしい順）→ 苦手の順に8問）。
- **空所補充**：例文の空所に入る語を選ぶ。**聞き取り**：読み上げられた語を選ぶ（音のちがいのセットのみ）。
- 習熟度は単語と同じ間隔反復（キーは `pair:セットID`）。
- 単語帳の詳細画面から、その語を含むセットを開ける。通常の学習（次のn語・復習）でも、セットに入っている語は習熟度2以上で「👯 似た単語」の問題が出る。

## 4. 問題

### 4.1 問題タイプ

| # | タイプ | 出題 | 回答 | 狙い | 出題される習熟度 |
|---|---|---|---|---|---|
| 1 | **カタカナ → 英語** | 「ポーション」+ シーン | 4択で正しい英単語 | 音から綴りへの橋渡し | 0〜2 |
| 2 | **英語 → 意味** | `potion` | 4択で日本語の意味 | 正確な意味の確認 | 0〜2 |
| 3 | **つづり** | 「ポーション」+ 意味 | 文字タイルを並べる | 綴りの定着（産出） | 2〜 |
| 4 | **語源** | 「ラテン語 pōtiō『飲み物』から生まれたのは？」 | 4択 | 語源による精緻化 | 2〜 |
| 5 | **類義語** | 「`elixir` の類義語は？」 | 4択 | 類義語ネットワーク | 3〜 |
| 6 | **カタカナの罠** | 「日本語の『テンション高い』を英語で言うと？」 | 4択 | 和製用法とのズレの修正 | 3〜（罠がある語のみ） |

- 出題文の中に答えの単語（や派生形）が含まれる場合は「＿＿＿」で伏せる。
- **4択の錯乱肢は正解に「近い」語から選ぶ**。見た目や種類の違いだけで消去できないようにするため。
  - 共通：同じ種類（一般の語／地名／人名／神名）を優先し、品詞・レベル（±2まで）・言語・語句かどうか・大文字始まりをそろえる。
  - 英単語を選ぶ問題（カタカナ → 英語・語源・類義語）：つづりが似た語（文字の並び・長さ・頭文字が近い）を優先する（例：box → book / boy / bow）。
  - 意味を選ぶ問題：意味の文の長さをそろえる。意味が重なる語と正解の類義語は、正解が2つになるので出さない。
  - 近い順の上位から少しゆらして選ぶので、同じ語でも毎回同じ組み合わせにはならない。錯乱肢どうしで同じカタカナ・同じ意味・同じつづりの語は1つだけにする。
- 問題は出す直前に作る（その時点の習熟度で出題タイプを選ぶ）。
- 制限時間はない。

### 4.2 補助

| ボタン | 効果 |
|---|---|
| 💡 ヒント | 問題タイプに応じたヒントを表示（例：カタカナ→英語なら意味、語源ならカタカナ表記）。1問1回 |
| ↩ 1文字もどす | つづり問題のみ |
| わからない | 不正解として扱い、答えと解説を表示する |

### 4.3 解説カード

正誤にかかわらず、回答直後に表示する（2〜4秒で読める量）。

```
┌───────────────────────────────┐
│ ✓ 正解！             ■■□□□  │  ← 緑／赤の帯。右は習熟度
├───────────────────────────────┤
│ potion  ポーション        🔊  │
│ （薬・魔法の）飲み薬           │
│ 📜 ラテン語 pōtiō「飲み物」    │
│ 💡 poison（毒）と兄弟語！      │
│ [📖 くわしく]       [つぎへ ›] │
└───────────────────────────────┘
```

- 不正解時は**自分が選んだ誤答の意味も表示**し、混同の原因を解消する。
- 類義語問題ではその類義語のニュアンスを、罠がある語は ⚠️ の注意書きを添える。

### 4.4 結果画面

正答率・正解数・連続日数と、**新しく出会った語／習熟度が上がった語／もう一度確認したい語（間違えた語）**を表示。各語をタップすると単語帳の詳細を開ける。途中でやめた場合も、そこまでの結果を表示して記録する。

## 5. 習熟度と復習

### 5.1 習熟度（ライトナー方式の5段階）

| 習熟度 | 名前 | 次の出題まで |
|---|---|---|
| 0 | 未学習 | — |
| 1 | 出会った | 当日 |
| 2 | 覚えかけ | 1日 |
| 3 | 定着中 | 3日 |
| 4 | 得意 | 7日 |
| 5 | 完璧 | 21日 |

- 正解で +1、不正解で −1（最低1）。5マスのメーターで表示し、段階ごとに色が変わる（ピンク → 黄 → 緑 → 水色 → 紫）。
- 習熟度3以上を「定着した語」として数える。
- 期限が来た語はホームの「きょうの学習」に件数が出て、「復習する」で最大20問出題する。

### 5.2 語根

- 同じ語根をもつ単語（例：`mon`「警告する」→ summon, monster）を**すべて習熟度3以上**にするとコンプリート。
- アプリ未収録の仲間の語（monitor, demonstrate…）も表示し、**1つの語根から語彙が広がる**体験を作る。

### 5.3 連続日数

- 1回でも学習した日を数える。**途切れても罰はない**（次に学習したとき「おかえりなさい」と表示するだけ）。

いつでも辞書として引けるように、**未学習の語も含めて全語を閲覧可能**にする。

- 詳細：英単語／カタカナ／品詞／CEFR／🔊発音、意味、習熟度、📍シーン、⚠️カタカナの罠、💬例文、📜語源、🧩語根、🌳同じ語源の仲間、🔀類義語（意味・ニュアンス・語源の表）

## 8. ビジュアル（テーマ）

機能はゲームにせず、手触りだけをゲームにする。見た目は4つのテーマから選べる（ヘッダーの 🎨、または「記録」タブ）。どのテーマでも機能・文言・レイアウトは同じ。中学生に人気のゲームの**雰囲気**を参考にしているが、ロゴ・キャラクター・画像・ゲーム内の文言は使わない。

| テーマ | 参考にした雰囲気 | 背景 | カード | ボタン | 見出し |
|---|---|---|---|---|---|
| **ステージ**（既定） | 音楽ゲーム（プロセカなど） | 白〜パステル、斜めの細線、ぼんやりした色の光 | 半透明の白＋すりガラス、左上にグラデーションの細線 | ティール→ブルーのグラデーションのピル、色つきの光る影 | 丸ゴシック。タイトルはティール→ブルー→ピンクのグラデーション文字 |
| **ポップ** | カジュアル対戦ゲーム（ブロスタなど） | 紫〜群青＋ドット | 白、3px の濃紺の縁、固い影 | 黄色の立体ボタン、押すと沈む | Dela Gothic One の白文字＋太い縁取り |
| **ストリート** | アーバンアクション（ゼンゼロなど） | 黒＋網点、斜めのネオンの帯 | 黒、左端にコース色の帯、右上に `/// VQ` | ネオンイエローの平行四辺形 | 斜体の白文字＋ネオンの影、見出しはステッカー風 |
| **ノーブル** | オープンワールドRPG（原神など） | 紺の夜空＋星 | 羊皮紙色、金の細い二重枠 | 金のグラデーションのピル | 明朝（Shippori Mincho B1）の金文字、◆と線の飾り |

- 仕組み：`<html data-theme="…">` を切り替える。共通部分は CSS 変数（色・縁の太さ・角丸・影・フォント）だけで描き、テーマ固有の装飾は `app/style.css` の末尾にまとめる。
- 選んだテーマは学習記録と同じセーブに保存し、ページ読み込み時に描画前に当てる（ちらつき防止）。
- テーマ選択画面の見本は、各テーマの変数でそのまま描いている。
- 共通の演出：選択肢の正解は緑＋✓でバウンド、不正解は赤＋✗で横に揺れる。結果画面は正答率70%以上でアイコンの後ろに光線が回る。進捗はステップバー（問題ごと）、進捗バー（次のn語）、円形リング（コース・語根）、5マスメーター（語）。

## 9. アクセシビリティ・配慮

- 正誤は色だけでなく ✓/✗ と文言で示す（色覚多様性）。
- 制限時間はない。
- 音声読み上げボタンを全単語に。`prefers-reduced-motion` で演出を止める。
- タップ領域 44px 以上。キーボード操作時はフォーカスリングを表示。

## 10. 計測指標（KPI）

| 指標 | 目的 |
|---|---|
| D1 / D7 継続率 | 習慣化できているか |
| 1回あたり正答率（目標 70〜85%） | 難易度が適切か |
| ヒント・「わからない」の使用率 | 難しすぎないか |
| 途中でやめた率（n別） | 長さ・難易度の調整 |
| 習熟度4以上の語数 | 長期記憶への定着 |
| 単語帳の詳細閲覧率 | 語源・類義語コンテンツが読まれているか |

## 11. データ構造

単語データは `data/words.json`、語根データは `data/roots.json`。人間向けの一覧は `docs/WORD_LIST.md`（自動生成）。コース・問題タイプ・習熟度の定義は `app/app.js` 冒頭の定数。

```jsonc
{
  "id": "potion",
  "word": "potion",
  "katakana": "ポーション",
  "pos": "名詞",                 // 固有名詞は 地名・神名・神話・人名。synonyms には別名・関連する名前を入れる
  "cefr": "B2",                 // A1〜C2。参考（画面には出さない）
  "level": 5,                   // 英検の級 1=5級, 2=4級, 3=3級, 4=準2級, 5=2級, 6=準1級, 7=1級。コース分けに使う
  "lang": "de",                 // （任意）英語以外の形で収録した語の言語（人名のドイツ語形など）。app.js の LANGS
  "group": "michael",           // （任意）同じ名前の別の言語形・男性形・女性形の仲間。選択肢に一緒に出さない
  "meaning": "（薬・魔法の）飲み薬、水薬",
  "scene": "RPGの定番回復アイテム。",
  "gap": "（任意）日本語での用法とのズレ",
  "trapQuiz": {                   // （任意）「カタカナの罠」問題。gap がある語のみ
    "question": "…", "answer": "…", "wrong": ["…", "…", "…"]
  },
  "example": { "en": "...", "ja": "..." },
  "etymology": { "origin": "ラテン語 pōtiō「飲み物」…", "story": "…" },
  "roots": ["pot"],               // roots.json の id
  "family": ["poison（毒）"],
  "synonyms": [
    { "word": "elixir", "meaning": "霊薬", "nuance": "…", "etymology": "…" }
  ]
}
```

学習記録はブラウザの localStorage（`vocab-quest-save-v3`）。旧 RPG 版のセーブ（`v2`）があれば、習熟度・連続日数・回答数だけを引き継ぐ。
