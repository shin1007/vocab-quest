# Vocab Quest — UX デザイン

> ゲーム・まんが・アニメで**すでに知っているカタカナ語**を足場にして、英単語を**RPGの冒険**として学ぶアプリ。

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| キャッチコピー | 「知ってるカタカナが、英語へのワープポイントになる。」 |
| ジャンル | クラシックな JRPG 風（ドット風フォント・ウィンドウ UI・コマンドバトル） |
| ターゲット | 中学生〜大学生、ゲーム・アニメ好きの社会人（英検3級〜準1級 / CEFR A2〜C1） |
| 学習上の強み | 音と大まかな意味をすでに知っている（＝ゼロからの暗記ではない）。残りの「正しい綴り・正確な意味・語源・類義語との差」を埋める |
| 体験の核 | **「あのポーションって、poison（毒）と兄弟だったのか！」**という“つながる驚き”を毎回届ける |

### 設計の3原則

1. **RPGのお約束 ＝ 学習の仕組み**：レベル・呪文・どうぐ・ボスといった RPG の要素を、それぞれ学習上の役割に対応させる（§3）。飾りとしてのゲーム要素は置かない。
2. **失敗しても前に進む**：負けても経験値は失わない（「きょうかいで めをさました」）。間違えたことばは「はぐれモンスター」として後で再登場する。
3. **1回3分**：1バトル＝5〜8問。通学中・ゲームの待ち時間にも終わる長さ。

## 2. 世界観とキャラクター

### 2.1 舞台：ことばの大陸

カタカナ語の力が英語の力に変わる大陸。4つの地方がジャンルに対応する。

| 地方 | ジャンル | ステージ（→ ボス） | 収録例 |
|---|---|---|---|
| 🏰 剣と魔法の王国 | RPG・ファンタジー | はじまりの草原 → まよいの森 → 古代遺跡 → **竜の城** | potion, quest, dungeon, summon |
| ⚔️ 闘技場の都 | バトル・アクション | 予選リング → 砂の闘技場 → 決勝の門 → **王者の玉座** | critical, combo, counter, rival |
| 🚀 星の方舟 | SF・ロボット | 発着ゲート → 無重力区画 → 動力炉 → **司令塔** | launch, gravity, dimension, portal |
| 🏫 カタカナ町 | 学園・スポーツ・ドラマ | 通学路 → 体育館 → 放課後の屋上 → **ワセイの館** | tension, smart, claim, cunning |

- 各地方の単語は **CEFR の易しい順**に並べ、約6語ずつステージに分ける。先に進むほど難しい語が出る。
- カタカナ町のボス「ニセモノ王ワセイ」は**和製英語・カタカナの罠**の化身。罠の多い地方のラスボスとして物語上の意味を持たせる。
- 4地方すべて最初から選べる（好きなジャンルから始められることを優先）。地方の中のステージは順番に解放。

> **著作権への配慮**：特定作品のキャラクター名・画像・台詞・呪文名は使わず、ジャンル共通の“あるある”で世界を作る。

### 2.2 主人公とジョブ

冒険の始めに**名前**と**ジョブ**を選ぶ。ジョブは「どう学びたいか」の選択で、優劣はない。

| ジョブ | 特徴 | 向いている人 |
|---|---|---|
| 🛡️ 戦士 | 最大HP +10 | ミスが多くても最後まで解きたい |
| 🧙 魔法使い | 最大MP +6 | ヒントを使いながら確実に覚えたい |
| 🗡️ 盗賊 | ゴールド ×1.5 | アイテムを集めたい |
| 📚 学者 | 経験値 ×1.2 | どんどんレベルを上げたい |

### 2.3 案内役：賢者ロゴス 🧙

ギリシャ語 *logos*（ことば）から名付けた NPC。マップ画面の上に常にいて、状況に応じて話す。

| 状況 | セリフの例 | 狙い |
|---|---|---|
| 復習期限のカードがある | 「はぐれモンスターが3体うろついておる。忘れかけた頃にもう一度戦うと心に深く刻まれるのじゃ」 | 復習への誘導と、間隔反復の理由づけ |
| 次のステージがある | 「次は まよいの森 じゃな。『ポーション』『クエスト』の気配がするぞ…」 | 次に学ぶ語の予告（先行オーガナイザー） |
| 全ステージクリア後 | 「知っておるか？ dungeon は…」 | 語源トリビアで再訪の動機づけ |

どうぐやの店主も語源ネタを話す（「potion と poison は語源が同じなんだぜ」）。

## 3. RPG 要素と学習の対応表

| RPG 要素 | 学習上の意味 |
|---|---|
| **ステージ** | 約6語の学習単位。易しい語から順に並ぶ |
| **敵のHP** | その回の理解度。全問に答えてはじめて倒せる（途中で削りきっても最後の1問まで「ふみとどまる」＝全語を必ず練習させる） |
| **こうげき（正解）** | 想起練習の成功 |
| **かいしんの いちげき** | 5秒以内の正解（すぐ思い出せる＝自動化の指標） |
| **コンボ** | 連続正解。ダメージ倍率 +0.5（最大×3） |
| **敵の攻撃・主人公のHP** | ミスの許容量。0 になると撤退（経験値は保持） |
| **じゅもん（MP）** | ヒント。使うほど MP が減るので「頼りすぎない」自然な制約になる |
| **どうぐ（ポーション等）** | ミスの許容量を買い足す手段。ゴールド＝学習量の報酬 |
| **レベル** | 累計学習量。上がると HP/MP が増え、新しい呪文を覚える |
| **ことばカードの★** | 間隔反復の段階（§5.1） |
| **はぐれモンスター** | 復習期限が来たカード |
| **ボス** | 地方の総まとめ。語源・類義語・カタカナの罠だけで出題 |
| **語根の宝珠** | 同じ語根の語を全部定着させると完成（§5.2） |

### 3.1 じゅもん

呪文名そのものも英単語にして、呪文を唱えるたびに英語に触れるようにする。

| 呪文 | 英語 | MP | 習得 | 効果 |
|---|---|---|---|---|
| リビール | reveal（明かす） | 4 | Lv1 | 4択の誤答を2つ消す／スペル問題は正しい次の1文字を置く |
| スキャン | scan（調べる） | 2 | Lv3 | 問題タイプに応じたヒントを表示（例：語源パズルならカタカナ表記） |

- 1問につき各呪文1回まで。MP はバトル開始時に全回復する。

### 3.2 どうぐ・ゴールド

| どうぐ | 価格 | 効果 |
|---|---|---|
| 🧪 ポーション | 10G | HP を 15 回復 |
| 🔷 エーテル | 15G | MP を 6 回復 |

- ゴールドは正解1問 5G、ステージクリア +20G、ボス撃破 +80G。初期所持 50G・ポーション3個。

## 5. バトル設計

### 5.1 画面構成（スマホ縦）

```
┌─────────────────────────────┐
│ まよいの森            3/6   │
│            🐺               │  ← 敵（被弾でフラッシュ、ダメージ数字がポップ）
│        シャドウウルフ        │
│      [██████░░░░░░]         │  ← 敵HP
├─────────────────────────────┤
│ ＊ シン の こうげき！         │  ← メッセージウィンドウ（直近3行）
│ ＊ かいしんの いちげき！      │
│ ＊ シャドウウルフに 30 のダメージ│
├─────────────────────────────┤
│ カタカナ → 英語              │  ← 問題ウィンドウ
│ ポーション                   │
│ ▶ potion                    │
│   portion                   │
├─────────────────────────────┤
│ 🪄じゅもん 🎒どうぐ 🏃にげる  │  ← コマンドウィンドウ
├─────────────────────────────┤
│ シン 🧙 Lv3  HP[███] MP[██]  │  ← 主人公ステータス
└─────────────────────────────┘
```

「たたかう」は選択肢を選ぶこと自体。答える前ならいつでも じゅもん／どうぐ を使える。

### 5.2 問題タイプ

| # | タイプ | 出題 | 回答 | 狙い | 難度 |
|---|---|---|---|---|---|
| 1 | **カタカナ → 英語** | 「ポーション」+ シーン | 4択で正しい英単語 | 音から綴りへの橋渡し | ★ |
| 2 | **英語 → 意味** | `potion` | 4択で日本語の意味 | 正確な意味の確認 | ★ |
| 3 | **スペル錬成** | 「ポーション」+ 意味 | 文字タイルを並べる | 綴りの定着（産出） | ★★ |
| 4 | **語源パズル** | 「ラテン語 pōtiō『飲み物』から生まれたのは？」 | 4択 | 語源による精緻化 | ★★ |
| 5 | **類義語ハンター** | 「`elixir` の仲間は？」 | 4択 | 類義語ネットワーク | ★★★ |
| 6 | **カタカナの罠** | 「日本語の『テンション高い』を英語で言うと？」 | 4択 | 和製用法とのズレの修正 | ★★★ |

- カードの★に応じて出題タイプを上げていく。★0〜1 はタイプ1・2、★2 でタイプ1〜4、★3 以上でタイプ3〜6。
- ボス戦はタイプ4〜6のみ。チュートリアルはタイプ1のみ（必ず答えられる易問）。
- 出題文の中に答えの単語（や派生形）が含まれる場合は「＿＿＿」で伏せる。

### 5.3 数値

| 項目 | 値 |
|---|---|
| 与ダメージ | 10 × コンボ倍率（1 + 0.5×(連続数−1)、最大×3）× かいしん（×2） |
| 敵HP | 問題数 × 10 × 1.2（ボス ×1.4、チュートリアル ×0.5） |
| 被ダメージ | 通常 10／ボス 13（チュートリアルは必ずかわす） |
| 主人公HP | 30 + 4×(Lv−1) + ジョブ補正 |
| 主人公MP | 8 + 2×(Lv−1) + ジョブ補正 |
| 経験値 | 正解 10、かいしん +5、ボス戦 +5／問、撃破ボーナス 20（ボス 60） |
| 次のレベルまで | 100 × 現在のLv |

### 5.4 回答直後の「ひらめきカード」

正誤にかかわらず、回答直後に小さなカードを表示する（2〜4秒で読める量）。

```
┌───────────────────────────────┐
│ ✅ 正解！            ★★☆☆☆   │
│ potion  ポーション        🔊  │
│ （薬・魔法の）飲み薬           │
│ 📜 ラテン語 pōtiō「飲み物」    │
│ 💡 poison（毒）と兄弟語！      │
│ [📖 ことばの書]      [▶ つぎへ]│
└───────────────────────────────┘
```

- 不正解時は**自分が選んだ誤答の意味も表示**し、混同の原因を解消する。
- 類義語問題ではその類義語のニュアンスを、罠がある語は ⚠️ の注意書きを添える。

### 5.5 バトルの結末

| 結末 | 条件 | メッセージ | 扱い |
|---|---|---|---|
| 勝利 | 全問回答後に敵HPが0 | 「〇〇を たおした！」 | 次のステージ解放・ボーナス |
| 逃げられた | 全問回答したが削りきれない | 「たおれずに にげていった…」 | EXP・G は獲得。再挑戦可 |
| 全滅 | 主人公HPが0 | 「……きょうかいで めをさました」 | **EXP・G は獲得**（罰なし） |
| にげる | コマンドで撤退 | 「うまく にげきった！」 | それまでの EXP・G は獲得 |

## 6. 成長・収集システム

### 6.1 ことばカードの★（＝間隔反復のボックス）

ライトナー方式の5段階を「カードのレア度」として見せる。

| ★ | 状態 | 次の出題まで |
|---|---|---|
| ☆0 | 未発見 | — |
| ★1 | 出会った | 当日 |
| ★2 | 覚えかけ | 1日 |
| ★3 | 定着中 | 3日 |
| ★4 | マスター | 7日 |
| ★5 | レジェンド | 21日 |

- 正解で★+1、不正解で★−1（最低★1）。リザルトで「しんかした ことばカード」として見せ、復習そのものを報酬にする。
- 期限が来たカードは**はぐれモンスター**としてマップ上部に出現。ステージ戦でも同じ地方の期限切れカードが混ざる。

### 6.2 語根の宝珠

- 同じ語根をもつ単語（例：`mon`「警告する」→ summon, monster）を**すべて★3以上**にすると宝珠が輝く。
- アプリ未収録の仲間の語（monitor, demonstrate…）も表示し、**1つの語根から語彙が広がる**体験を作る。

### 6.3 レベル・連続記録

- 経験値でレベルが上がり、最大HP/MP が増え、Lv3 で呪文「スキャン」を覚える。
- 連続プレイ日数を表示。ただし**途切れても罰はない**（「おかえり！」のメッセージのみ）。

## 7. ことばの書（単語リスト参照）

いつでも辞書として引けるように、**未発見の語も含めて全語を閲覧可能**にする（未発見はグレー表示で収集欲を刺激）。長文が多いので、この画面だけは読みやすいゴシック体で表示する。

- 一覧：検索（英語・カタカナ・意味・類義語）、地方フィルター、⚠️カタカナの罠のみ
- 詳細：英単語／カタカナ／品詞／CEFR／🔊発音、意味、🎮シーン、⚠️カタカナの罠、💬例文、📜語源、💎語根、🌳同じ語源の仲間、🔀類義語（意味・ニュアンス・語源の表）

## 9. ビジュアル・演出

- **ウィンドウ**：濃紺の地に白い二重枠の角丸ウィンドウ。ボタンは押し込み感のある影付き。
- **フォント**：UI は DotGothic16（ドット風）。ことばの書・ヒントなど長文はゴシック体。
- **演出**：被弾で敵がフラッシュ＆揺れ、ダメージ数字ポップ、かいしんは黄色の大きな数字、被ダメージで画面が揺れる、ふみとどまった敵はふらふら揺れる、撃破で倒れる。
- ひらがな多めのメッセージ（「〇〇の こうげき！」）で“らしさ”を出す。学習内容（意味・語源）は漢字かな混じりで正確に。

---

## 10. アクセシビリティ・配慮

- 正誤は色だけでなく ✅/❌ アイコンで示す（色覚多様性）。
- タイマーは「かいしん」判定のみに使い、**制限時間で不正解にはしない**。
- 音声読み上げボタンを全単語に。`prefers-reduced-motion` で演出を止める。
- タップ領域 44px 以上。

## 11. 計測指標（KPI）

| 指標 | 目的 |
|---|---|
| D1 / D7 継続率 | 習慣化できているか |
| 1バトルあたり正答率（目標 70〜85%） | 難易度が適切か |
| 勝利率・全滅率（ステージ別） | 敵HP・被ダメージの調整 |
| 呪文の使用率 | ヒントに頼りすぎていないか・難しすぎないか |
| ★4 以上のカード数 | 長期記憶への定着 |
| ことばの書の詳細閲覧率 | 語源・類義語コンテンツが読まれているか |

## 12. データ構造

単語データは `data/words.json`、語根データは `data/roots.json`。人間向けの一覧は `docs/WORD_LIST.md`（自動生成）。地方・ステージ・敵・ジョブ・呪文・どうぐの定義は `app/app.js` 冒頭の定数。

```jsonc
{
  "id": "potion",
  "word": "potion",
  "katakana": "ポーション",
  "pos": "名詞",
  "area": "fantasy",            // fantasy | battle | scifi | story（＝地方）
  "cefr": "B2",                 // ステージの並び順に使う
  "meaning": "（薬・魔法の）飲み薬、水薬",
  "scene": "RPGの定番回復アイテム。",
  "gap": "（任意）日本語での用法とのズレ",
  "trapQuiz": {                   // （任意）「カタカナの罠」問題。gap がある語のみ
    "question": "…", "answer": "…", "wrong": ["…", "…", "…"]
  },
  "example": { "en": "...", "ja": "..." },
  "etymology": { "origin": "ラテン語 pōtiō「飲み物」…", "story": "…" },
  "roots": ["pot"],               // roots.json の id
  "family": ["poison（毒）"],
  "synonyms": [
    { "word": "elixir", "meaning": "霊薬", "nuance": "…", "etymology": "…" }
  ]
}
```

### 今後の拡張案

- 単語の追加（目標 300 語）と、それに合わせた地方・ステージの追加（音楽・料理・ファッション など）
- 仲間キャラ（語根ごとの精霊など）がパーティに加わるシステム
- 装備（語根の宝珠を装備すると特定の問題タイプで与ダメージアップ）
- 音声入力による「詠唱」（発音チャレンジで呪文を唱える）
- 語源データの出典欄（Online Etymology Dictionary、OED 等）の追加と監修
